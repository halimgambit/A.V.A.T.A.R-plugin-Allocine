# Allocine
Allociné vous permet de consulter les séances de votre cinéma

This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework.

🎯 Usage
Commandes :

il y'a quoi au cinema, les films à l'affiche,
les horaires de Matrix,
quels est la séance de bob l'éponge

https://www.allocine.fr/seance/salle_gen_csalle=C0146.html#shwt_date=2026-06-10

A renseigner l'id de votre salle de cinéma sur le fichier .prop

# Multi-room
The Allocine plugin is fully multi-room.

# Multi-language
The Allocine plugin relies solely on the system's available languages.
